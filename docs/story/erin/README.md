# Erin story prompts

Tracked Seedream i2i prompts for Erin plates. Binaries are not in git (R2 +
`cdn-backup/`). A plate without its prompt cannot be re-rolled.

Current files are reverse-engineered from the **shipped** plates (ep 2 is 23
story pages). Title splash `erin-ep2-p01-title-forest-castle.txt` is reader
page 1 (Erin alone — no army). The end plate is reader page 23. The older
`…-castle-army.txt` slug kept the goblins.
Names land on p06 handshake. p06 bottom is Venus trapping the
gargoyle pieces in dirt — not a second earth-golem (the `earthform` slug is
historical). Older generation notes keep a different slug (campfire vs sleep,
splash kidnap vs three-panel carry, p04 descent vs the old handshake / thanks
drafts).

Build new pages with `/erin-toon-page`. Save here, no timestamps:

```

```
